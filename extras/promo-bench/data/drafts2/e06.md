가계부 앱이 2.4 버전으로 업데이트되었습니다.

이번 업데이트에서 가장 많이 요청하셨던 기능을 넣었어요. 영수증 사진을 찍으면 금액과 날짜를 자동으로 읽어 입력해 줍니다. 입력이 잘못된 부분은 바로 고칠 수 있어요.

주요 변경 사항은 다음과 같습니다.
- 영수증 자동 입력 (베타, 국내 카드사 영수증 우선 지원)
- 월별 예산 초과 시 알림 시점 설정
- 고정 지출 등록 시 매달 자동 반영
- 통계 화면에서 카테고리 비율을 원형 그래프로 확인

기존 데이터는 그대로 유지되고, 별도 작업 없이 업데이트만 하시면 돼요. 다만 자동 입력 기능은 처음 실행할 때 카메라와 사진 접근 권한을 요청하니 허용해 주세요.

알려 주신 버그 중 결제 내역이 중복 표시되는 문제도 함께 고쳤어요. 불편을 드려 죄송합니다. 더 좋은 앱이 되도록 의견도 계속 받고 있어요. 감사합니다.
